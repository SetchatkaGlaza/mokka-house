# MOKKA HOUSE

Адаптивный сайт городской кофейни: полноэкранное видео на первом экране, интерактивное меню, галерея с увеличением фото, анимации появления блоков и мобильная навигация.

## Запуск

Сборка не нужна — это статический сайт на HTML, CSS и JavaScript. Откройте `index.html` в браузере или запустите локальный сервер:

```bash
npx serve .
```

## Структура

```
index.html
favicon.svg / favicon.ico / apple-touch-icon.png / site.webmanifest
src/styles/main.css
src/scripts/main.js
public/images/   фотографии (WebP), OG-превью, иконки
public/video/    видео и постеры
```

## Публикация на GitHub Pages

Settings → Pages → Deploy from a branch → `main` / `(root)`.

## Что можно настроить

- Меню и цены — массив `MENU` в начале `src/scripts/main.js`.
- Адрес, телефон, часы работы — блок `#contacts` в `index.html` и разметка JSON-LD в `<head>`.
- Ссылки на соцсети — блок `.soc` в `index.html`.
- Цвета — переменные в начале `src/styles/main.css`.

## Особенности

- Управление с клавиатуры, видимый фокус, ссылка «К содержимому».
- При включённом «уменьшении анимации» видео не воспроизводится, эффекты отключаются.
- Видео подгружается лениво и ставится на паузу вне экрана.
